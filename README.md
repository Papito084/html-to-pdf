# 📄 HTML to PDF Converter

Una herramienta profesional, rpida y elegante para convertir instantneamente archivos HTML locales o cdigo HTML puro en documentos PDF perfectamente formateados, conservando estilos e imgenes.

## 🚀 Caractersticas
- **Conversin de Alta Fidelidad:** Renderiza CSS complejo, tablas, fuentes e imgenes de forma precisa y los exporta a pginas PDF de tamao A4 (formato estndar).
- **Editor y Visor en Tiempo Real:** Interfaz amigable para subir tu archivo `.html` o simplemente pegar tu cdigo y previsualizarlo antes de exportar.
- **Procesamiento Local Seguro:** Utiliza potentes libreras como `jsPDF` y `html2canvas` para procesar todo del lado del cliente en tu navegador. Tus documentos confidenciales nunca se suben a ningn servidor de internet.
- **Diseo Moderno:** UI/UX pulida, con tema oscuro (Dark Mode), moderna y con calidad de software profesional, incluyendo icono personalizado (squircle transparente).

## 🛠️ Cmo usarlo
1. Clona o descarga el repositorio en tu ordenador.
2. Abre el archivo `index.html` en tu navegador web. (O tambin puedes ejecutar el acceso directo incluido).
3. Arrastra tu archivo `.html` a la zona de subida, o pega directamente tu cdigo en el editor provisto.
4. Presiona el botn "Convertir a PDF" y tu documento finalizado se descargar automticamente en cuestin de segundos.
